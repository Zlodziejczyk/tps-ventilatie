# Quick Task 260812-311: Brand favicon from the TPS emblem

## Why now

`app/favicon.ico` was still the create-next-app scaffold icon — same `Mar 23 14:48`
timestamp as `next.svg` / `vercel.svg` / `window.svg`. The live site was serving it
(`/favicon.ico` → 200, `image/vnd.microsoft.icon`, 25931 bytes), so every tab showed
the Next.js mark instead of TPS.

## Source and constraint

`public/tps-logo.png` — 1369×1149, RGB, no alpha. The emblem is a ring with a
snowflake (upper-left), `TPS` centred, a flame (lower-right), and a
`KLIMAATTECHNIEK` sub-wordmark under the `TPS`.

Owner decision: **keep the emblem, drop the KLIMAATTECHNIEK line** — it is
illegible below ~48px and only muddies the mark.

The sub-wordmark sits *inside* the emblem, so it cannot be cropped away, and no
ImageMagick is available on this machine (only `sips`, which cannot paint regions).
Handled with a dependency-free Node PNG decode/encode (`node:zlib` only).

## Measurements (not guesses)

Row-profiling the ring interior (x 330–1250) by dark-pixel count and segment count
separates lettering from the solid ring arc:

| y range | segments/row | what |
|---|---|---|
| 396–645 | ~3 | `TPS` lettering |
| 646–675 | 0 | clean gutter |
| **676–727** | **20–23** | **`KLIMAATTECHNIEK`** (many letter runs) |
| 728+ | 1–3 | ring arc only |

Paint box used: x 360–1215, y 668–733 (margin inside both gutters; clear of the
`TPS` baseline at 645 and the flame which starts ~776).

## Tasks

### Task 1 — Derive the mark

- Paint the measured wordmark box white.
- Re-measure the emblem bbox (x 34–1306, y 39–1059) and centre it on a square
  canvas with ~4% breathing room → 1374×1374.
- Flood-fill from the border across near-white pixels to make the *outside* of the
  ring transparent, so the icon reads as a disc rather than a white tile.
  **Guarded:** the fill only escapes inward if the ring has a gap, so the script
  asserts the centre pixel is still opaque before accepting the result. It passed —
  the ring is closed (75.3% of the canvas filled, interior intact).

### Task 2 — Emit the icon set

| File | Source | Size | Why |
|---|---|---|---|
| `app/icon.png` | disc (transparent) | 256×256, 54 KB | Next.js App Router emits `<link rel="icon">`; browsers downscale better than a hand-made 32px. 512 was 167 KB — not worth it for a favicon. |
| `app/apple-icon.png` | **opaque** white square | 180×180, 35 KB | iOS ignores alpha and composites on black — a transparent disc would show black corners. |
| `app/favicon.ico` | disc | 16+32+48, 7 KB | Legacy and bare `/favicon.ico` requests. PNG-compressed ICO entries (universal since IE11). |

**Verify:** ICO header parses — `type=1`, `count=3`, every entry a real PNG.
**Done:** default Next.js icon no longer present anywhere in the tree.
