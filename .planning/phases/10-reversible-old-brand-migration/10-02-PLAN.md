<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| third-party live production box → this machine | `wget` fetches from a server we do not own and must not stress; `--wait=1 --random-wait` and a bounded depth are the courtesy |
| crawled public HTML → the git repository | anything committed becomes permanent and public; the crawl must not carry secrets or personal data |
| Homebrew → the dev machine | `wget` is a system utility on this machine only, never a project dependency |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-10-mirror-pii | Information disclosure | the committed mirror | mitigate | unauthenticated crawl of public pages only; `robots.txt` respected (no `-e robots=off`); automated gate asserts no `wp-admin`/`wp-login`/`wp-json` artefact and that the only address present is the public `info@tpsventilatie.nl` |
| T-10-mirror-scope | Information disclosure | crawl boundary | mitigate | `--domains=tpsventilatie.nl` + `--no-parent` + `--level=2` + explicit seed list; no `--mirror` |
| T-10-repo-bloat | DoS | git history | mitigate | footprint measured with `du -sh` and asserted under D-28's ~25 MB ceiling; the external-storage branch is documented |
| T-10-path-traversal | Tampering | wget output paths on the OneDrive mount | mitigate | `--restrict-file-names=windows` and a fixed `--directory-prefix` |
| T-10-SC | Tampering | npm/pip/cargo installs | mitigate | no npm packages added; `wget` is a GNU core utility installed via Homebrew on the dev machine only, never in `package.json` and never in the Vercel build (RESEARCH §Package Legitimacy Audit) |
</threat_model>
