<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| repo (public, OneDrive-synced) → service-account key | a private key that grants read access to both properties |
| CI logs (public) → token material | Actions masks only exact secret values; a derived access token is not masked |
| scripts → Google APIs | untrusted responses; enum values and counts must be validated, never trusted blindly |
| scripts → Search Console write surface | `sitemaps.submit` exists in the same API family and must never be called by these scripts |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-9-key | Information disclosure | SA JSON key | mitigate | stored at `~/.config/tps-klimaattechniek/` (outside OneDrive tree, chmod 600) + GitHub secret only; `.gitignore` patterns; verify asserts no key is tracked |
| T-9-token-log | Information disclosure | `auth.ts`, `api.ts` errors | mitigate | errors carry status codes only; verify greps for token logging; no response bodies in messages |
| T-9-scope | Elevation | SA permissions | mitigate | Full (not Owner) on exactly two properties; token minted with the read-only scope; SA has no GCP IAM roles |
| T-9-write-api | Tampering | Search Console API | mitigate | no `submit`/`delete` methods implemented; verify greps reject `sitemaps/submit` and PUT |
| T-9-untrusted-response | Tampering | API JSON | mitigate | typed unions; `submitted`/`errors` compared to `INDEXABLE_FLOOR`/0; `indexed` never read |
| T-9-quota | DoS | URL Inspection / Search Analytics | accept | ~60 calls per export vs 1,200 QPM / 2,000 QPD limits |
| T-9-key-creation-blocked | Repudiation | GCP org policy | accept (documented) | RESEARCH A6 fallback (Workload Identity Federation) requires re-planning; stop and record |
| T-9-SC | Tampering | npm installs | accept (n/a) | no packages installed; verify rejects `googleapis`/`google-auth-library` imports |
</threat_model>
